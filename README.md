# 此刻 · 情绪音乐播放器

EE 黑客松 / 创意文娱赛道。工作名「此刻」，围绕关键词「情绪价值」：选择当下心情，让音乐和同步文字陪你待一会儿。

## 启动

需要 Node.js >= 22.18、npm 和现代浏览器。首次安装需要联网，已安装依赖后原创演示模式可离线使用。

    cd 源码
    npm ci
    npm run dev

打开终端显示的地址（默认 http://127.0.0.1:5173）。当前机器已装好依赖，直接 npm run dev 即可。点击「开始这一刻」播放并进入沉浸页。

## 当前功能

- 三种心情编排、歌单、本地搜索、浏览器收藏。
- 单实例播放器：队列、播放/暂停、进度、音量、循环；切换页面不断播。
- 沉浸文字：时间同步、点击跳转、手动滚动后暂停跟随与返回当前句。
- 3 首各 48 秒的本站原创合成器乐；原创 SVG 封面及同步聆听文字。没有人声，聆听文字不是演唱歌词。
- 网易云在线适配器遵循 docs/接口契约.md，开发代理到 3001 端口；在线失败明确显示，不自动切换演示数据。真实后端由 B 负责，尚未在本窗口联调。

## 检查与生产预览

    npm test
    npm run build
    npm run preview

浏览器验收：另开终端保持 npm run dev，先运行 npx playwright install chromium，再运行 npm run test:browser。脚本检查 1440×900、1280×800、390×844，截图放在 源码/test-results/。执行环境限制使本窗口无法启动 Chromium 或监听端口，不能声明已完成截图验收。用户已在自己的终端确认「可以播放，沉浸页正常」。

音频和封面可用 Python 3 标准库重新生成：在 源码/ 执行 python3 scripts/generate-demo.py。
