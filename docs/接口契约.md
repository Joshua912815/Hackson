# 音乐服务接口 v1

2026-10-18：A 定义前端契约、B 实现服务端。当前是约定，不是已部署接口。前缀 /api，服务端默认端口 3001，JSON UTF-8。ID 使用字符串，时长和歌词时间使用毫秒。

## 公共对象

- Track：id、source（demo / netease）、title、artists（字符串数组）、album、durationMs、coverUrl（可空）、availability（unknown / full / preview / unavailable）、可选 reason。
- Playlist：id、source、title、description、coverUrl（可空）、trackCount。
- Playback：kind（full / preview / unavailable）、url（可空）；preview 必须有 previewStartMs、previewEndMs；可选 expiresAt、reason。在线 URL 为 http(s)；本地演示允许 blob。
- LyricLine：timeMs、text。Lyrics：kind（synced / plain / none）、lines、可选 plainText。无歌词为 none，接口失败则返回错误。

## HTTP 端点

| 方法和路径 | 参数 | 响应 |
| --- | --- | --- |
| GET /api/health | 无 | { status: "ok", source: "netease", capabilities: ["search", ...] } |
| GET /api/discovery | mood 可选 calm / energy / comfort | { playlists: Playlist[], tracks: Track[] } |
| GET /api/search | q 1–100 字、cursor 可选 | { tracks: Track[], total: number, nextCursor: string 或 null } |
| GET /api/playlists/:id | cursor 可选 | { playlist: Playlist, tracks: Track[], nextCursor: string 或 null } |
| GET /api/tracks/:id/playback | 无 | Playback |
| GET /api/tracks/:id/lyrics | 无 | Lyrics |

精选内容不冒充个性化推荐，分页和总数真实。演示服务实现同一 MusicService，不要求 HTTP；在线失败仅显示错误与重试，用户主动切换后才用演示数据。

## 错误与安全

HTTP 400 / 401 / 403 / 404 / 429 / 502 / 503，响应 { error: { code, message, retryable } }。code：INVALID_INPUT、AUTH_REQUIRED、FORBIDDEN、NOT_FOUND、RATE_LIMITED、UPSTREAM_ERROR、NOT_CONFIGURED。

不能把原始上游异常、Cookie、Authorization、密钥或含凭据 URL 放入响应或日志。服务端只访问固定或受控上游，不做任意 URL 代理；请求设超时。登录如必需，B 先在文档提出端点，再由 A 接 UI。前端快切会取消旧请求并忽略过期结果。

## B 的交付

独立服务启动命令、无秘密的配置示例、至少一个实测曲目 ID、已支持端点、失败样例、运行环境、上游来源 / 固定版本 / 许可。不确定项写“未验证”。
