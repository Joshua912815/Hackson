# 90 秒展示稿与操作

## 开场 15 秒

“我们做的是「此刻」，一个让文字和音乐一起接住情绪的播放器。面对同一段旋律，不同的人需要安静、能量或者陪伴，所以我们把心情变成音乐入口和字幕的表达方式。”

## 演示 60 秒

1. 首页选「需要一点能量」，点击「开始这一刻」。现场确保电脑已开声音，当前为原创演示模式。
2. 沉浸页默认「字幕演出」：展示逐字入场、关键词强调与同步进度。等到 12 秒看竖排构图；可拖进度到 18 秒比较横排，暂停时字幕同时暂停。
3. 点「留白／微光／接住」，同一句文字用不同的配色和入场方式表达。说明动效随实际音频时间驱动，不是另起一段视频。
4. 点「滚动文字」，点击一句文字跳转；返回发现，音乐继续。打开队列，展示真实播放状态。

## 收尾 15 秒

“这次对应的主关键词是情绪价值：让用户先表达现在的感受，再用音乐和 MAD 风格文字构成一个短暂的情绪空间。演示器乐、封面和聆听文字是本站生成的原创素材；器乐没有人声，文字是陪伴文案。网易云接入以最终实际联调范围介绍。”

## 演示准备

- 开始前运行 npm run dev；需要生产预览时先 npm run build，再 npm run preview。
- 优先用原创演示模式，现场没有网络仍能播。切到在线失败时明确解释真实接入状态。
- 用户已在本机反馈新增字幕效果正常。最终电脑再完整走一次；若异常，切回「滚动文字」继续展示稳定播放。
- 视频导出、自动节拍识别、歌词逐词强制对齐、影视素材二创均未实现，不列为成果。
